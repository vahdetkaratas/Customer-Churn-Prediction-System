# Data

- **`raw/`** — Download [Telco Customer Churn from Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) and save as `telco_customer_churn.csv`.  
  CSV files under `raw/` are **gitignored** (size + redistribution). The folder is kept via `.gitkeep`.

Training reads the raw CSV only; there is no checked-in processed dump.
